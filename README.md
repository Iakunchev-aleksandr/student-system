# Учебная информационная система (учебный журнал)

Веб-приложение для студентов и преподавателей: расписание, оценки, посещаемость,
уведомления об экзаменах/активностях, комментарии и файлы преподавателя, личные заметки студента.

**Стек:** Spring Boot 3.3 · Thymeleaf (серверный HTML + CSS) · Spring Security · Spring Data JPA · PostgreSQL · Java 17.

---

## Требования

- JDK 17+
- Maven 3.9+ (или используйте `./mvnw`, если добавите wrapper)
- PostgreSQL 13+

## Настройка базы данных

Создайте пустую базу (имя по умолчанию — `school`):

```bash
createdb school
# или в psql:  CREATE DATABASE school;
```

При необходимости поменяйте логин/пароль/имя БД в `src/main/resources/application.properties`:

```
spring.datasource.url=jdbc:postgresql://localhost:5432/school
spring.datasource.username=postgres
spring.datasource.password=postgres
```

Таблицы создаются автоматически при первом запуске (`spring.jpa.hibernate.ddl-auto=update`).

## Запуск

```bash
mvn spring-boot:run
```

Откройте http://localhost:8080 — откроется страница входа.

При первом запуске пустая база заполняется демонстрационными данными **на японском**
(см. `config/DataSeeder.java`). Если база уже не пустая, сидер ничего не делает.

> ⚠️ **Нужно пересоздать базу.** Схема изменилась: имя пользователя разделено на
> фамилию/имя, добавлены номер студента и фото, у групп теперь два поля (год обучения
> и код группы). `ddl-auto=update` не переносит данные между старыми и новыми колонками,
> поэтому базу нужно создать заново:
> ```bash
> dropdb school && createdb school
> ```
> После перезапуска сидер заполнит её актуальными японскими демо-данными.

## Языки интерфейса (i18n)

Интерфейс доступен на трёх языках: **японский** (по умолчанию), **английский** и **русский**.
Переключатель (日本語 / English / Русский) есть в верхней панели и на странице входа.

- Тексты вынесены в `src/main/resources/messages*.properties`
  (`messages.properties` — японский/базовый, `messages_en.properties`, `messages_ru.properties`).
- Язык хранится в сессии; выбор меняется параметром `?lang=ja|en|ru`
  (см. `config/I18nConfig.java` — `SessionLocaleResolver` + `LocaleChangeInterceptor`).
- Язык по умолчанию для нового посетителя — японский, независимо от языка браузера.
- Чтобы добавить язык, создайте `messages_<код>.properties` и пункт в переключателе
  (`templates/fragments/common.html`, фрагмент `langswitch`).

## Роли и доступ

- **Студент** видит только свои данные: недельное расписание, а по клику на день — свои оценки,
  посещаемость, уведомления, комментарии и файлы преподавателя. Может оставить заметку на день
  (с галочкой «показать преподавателю»).
- **Преподаватель-предметник** видит только свои уроки и студентов этих уроков; на странице урока
  ставит оценки/посещаемость, пишет комментарии, прикрепляет файлы, создаёт события.
- **Классный руководитель** дополнительно видит полное расписание, состав своей группы и
  **сводку оценок всех студентов группы за неделю** (`/teacher/class/{id}`).
- **Администратор** имеет максимальный доступ: ведёт справочники (пользователи, группы, предметы),
  собирает шаблон расписания и генерирует уроки, **редактирует и удаляет любые записи**, а через
  «Журнал» (`/admin/journal`) открывает любой урок и правит оценки/посещаемость.

Разграничение реализовано в `service/AccessService.java` и в `security/SecurityConfig.java`
(администратору открыт доступ к страницам урока преподавателя).

## Пользователи и группы

- Имя пользователя хранится двумя полями — **фамилия** и **имя** (отображается «Фамилия Имя»).
- У **студента** есть уникальный **6-значный номер** (задаётся администратором, проверяется формат и уникальность).
- Любому пользователю можно загрузить **фото** при создании или редактировании (хранится в `uploads/`,
  отдаётся через `/users/{id}/photo`).
- **Группа** задаётся двумя полями — **год обучения** и **код группы**; отображается как «1年A組»
  (см. `SchoolClass.getName()`).
- Удаление защищено проверками целостности: студент удаляется вместе со своими оценками/посещаемостью/
  заметками; преподавателя, группу или предмет нельзя удалить, пока на них есть ссылки.

## Как устроено расписание

1. Админ заводит **группы**, **предметы**, **преподавателей**.
2. На странице «Шаблон расписания» собирает повторяющиеся недельные слоты (`ScheduleTemplate`).
3. На странице «Генерация» разворачивает шаблон в конкретные датированные уроки (`Lesson`)
   за выбранный период. Генерация идемпотентна — повторный запуск не создаёт дубликатов
   (`service/ScheduleGenerationService.java`).

Оценки, посещаемость, комментарии и файлы привязаны именно к датированному уроку, а не к слоту.

## Файлы преподавателя

Загруженные файлы хранятся на диске в папке `uploads/` (создаётся автоматически; путь задаётся
свойством `app.upload-dir`). В БД хранится только метаинформация (`FileAttachment`).
Скачивание — через `/files/{id}` для любого аутентифицированного пользователя.

## Структура проекта

```
src/main/java/com/school
├── model/      JPA-сущности (AppUser, SchoolClass, Subject, ScheduleTemplate,
│               Lesson, Grade, Attendance, SchoolEvent, StudentNote,
│               TeacherComment, FileAttachment + перечисления)
├── repo/       Spring Data репозитории
├── security/   CustomUserDetailsService, SecurityConfig (роли, вход/выход)
├── service/    CurrentUserService, AccessService, ScheduleGenerationService, FileStorageService
├── web/        Контроллеры (Auth/Student/Teacher/Admin/File/UserPhoto) + DTO для шаблонов
└── config/     DataSeeder (демо-данные), I18nConfig (локали)

src/main/resources
├── templates/  Thymeleaf-шаблоны (fragments/common.html — каркас; admin/*-edit.html — формы правки)
├── static/css/ app.css
├── messages*.properties  тексты интерфейса (ja/en/ru)
└── application.properties
```

## Возможные расширения

- Принудительное (каскадное) удаление преподавателей/групп/предметов со всеми связями.
- Раздельные «личная заметка» и «сообщение преподавателю» (сейчас одна заметка на день с флагом видимости).
- Пагинация и фильтры в админских списках.
- Ограничение типа/размера загружаемого фото, обрезка до квадрата.
